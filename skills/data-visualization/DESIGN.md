# Data Observatory design contract

The audience is a curious analyst exploring evidence, comparing cohorts, and understanding change. The artifact is an analytical workspace, not a marketing page. Its objects are datasets, observations, fields, views, a cohort, an observed time cursor, selected entities, and saved questions.

The system-drawings sibling relationship includes both architecture and visual language: an agent authors a declarative document; an engine renders it; a verifier checks the result; a portable HTML artifact works without a service. The reference is `/opt/projects/system-drawings/skills/system-drawings/references/design-principles.md`. Use position and length before area, stable category symbols and line patterns, fixed domains during playback, explicit units, and visible sources.

The visual reference is a 1970s NASA/IBM engineering sheet: pure white paper, black ink (#111), secondary lettering (#555), faint gray lines, and square controls with thin black borders. Sheet titles use small uppercase Helvetica-style lettering; labels, controls, values, and chart lettering use monospace. The plot carries the emphasis. Selection uses stroke weight and black/white inversion. Categories use consistent symbols, open/filled marks, and line patterns; bar outlines remain visible when fills are white. No chromatic accents, serif display type, oversized headings, decorative branding, shaded page regions, gradients, shadows, floating cards, or ornamental KPI tiles.

The signature interaction is the shared observed-time controller. Scrubbing or playing updates all linked views and rows; selection preserves entity identity across frames. A selected mark opens its record alongside the chart. An optional two-dimensional brush defines the cohort. Comparison uses visible counts and fixed axes; it does not conceal excluded observations. Source caveats remain visible below the title and source details are one action away.

The main view gets the largest area. Supporting information sits in a narrow right column on wide screens and below the chart on phones. The hierarchy is plot, compact sheet title, controls, then methodological detail. Counts read as a quiet record table, never as headline statistics. Tabs choose a view; chart/data/source tabs change presentation of the same cohort. The saved questions are short, inspectable state changes. There is no simulated AI chat.

Tokens live only in assets/style.css. Minimum touch target is 36px (44px on compact screens), focus outlines are visible, controls have text labels, tables provide keyboard access to every mark, and reduced motion disables automatic playback. The runtime is scoped to its own Shadow DOM, owns its event handlers and timer, and can be disposed without affecting another instance.
